# 🌙 Fiche de montage Printful — Collection AFTER MIDNIGHT (8 produits)

Objectif : créer les 8 produits sur **Printful**, générer les mockups, puis les
mettre en ligne sur vicehubx.com. Suis les produits dans l'ordre. Tout est prêt :
blank conseillé, design recto, design verso, placement, prix.

> ⚠️ **Astuce impression (à lire une fois)** : les artworks **plein-dos 4K**
> (P01, P02, P04, P05, P06) ont un **fond sombre plein**. Sur un t-shirt **noir**,
> ça rend très bien mais l'impression est une **zone rectangulaire** (l'encre pose
> un rectangle). Choisis donc **toujours le vêtement NOIR** pour que le fond de
> l'artwork se fonde au tissu, et **commande 1 échantillon** avant d'ouvrir les
> ventes pour valider le rendu du bord. (Si tu préfères un dos “sans rectangle”,
> je peux regénérer ces dos sur **fond transparent** plus tard — dis-le-moi.)

| **P08** | Tote coton **noir** | Centre | — | 24,90 € |

Étapes dans Printful (identiques pour chaque produit) :
1. **Choisis le blank** ci-dessus → couleur **Noir** → sélectionne les tailles (S–2XL).
2. **Upload le design recto** → place selon la colonne « recto ».
3. Onglet **Back** → **upload le design verso** → place selon la colonne « verso ».
   *(P07/P08 : recto seul. P07 = choisir l'option **broderie**.)*
4. **Génère les mockups** → choisis le mockup **face noir** le plus net comme visuel principal, **télécharge-le**.
5. **Enregistre** le produit (ou pousse-le vers ton store). Note son **ID / sync variant**.

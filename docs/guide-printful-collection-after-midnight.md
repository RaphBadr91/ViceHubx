## 2) Placer les fichiers (réglages PRO)

Ouvre le **Design Maker** du produit. Onglets **Front** / **Back** (et **Right chest** pour les petits logos).

### Petits logos poitrine (pièces 1, 2, 4, 5, 6)
- Onglet **Left chest / Right chest** (pas « Front » plein centre).
- Taille du visuel : **~8–10 cm de large**. Placement : poitrine gauche, à ~18–20 cm du col.
- Vérifie le **DPI** affiché : doit rester **vert / ≥150 DPI** (nos PNG sont larges, aucun souci).

### Slogans / gros texte devant (pièce 3 « NEON NEVER SLEEPS »)
- Onglet **Front**, centré haut-poitrine, **~26–28 cm de large**.

### Artworks plein-dos (pièces 1, 2, 4, 5, 6)
- Onglet **Back**, centré. Étire jusqu'à la zone d'impression max (**~30 × 40 cm** / 12×16").
- Laisse ~8 cm sous le col (le haut du dessin commence sous la couture d'épaule).

### Badge haut-de-dos (pièce 3, fichier `9cfa996a`)
- Onglet **Back**, mais **petit** (~12–15 cm), placé **en haut** entre les omoplates (style « yoke »).

### Casquette (pièce 7) — BRODERIE
- Produit casquette → onglet **Front**. La broderie accepte **3–4 couleurs**, pas de dégradé.
  Notre fichier est déjà simplifié pour ça. Garde-le **petit et net** (~6 × 6 cm).

### Tote (pièce 8)
- Un seul côté, centré, **~24 × 30 cm**.

> **Impression sur noir (important) :** Printful applique automatiquement une **sous-couche
> blanche** en DTG sur tissu foncé → les néons ressortent. Le **fond transparent** de nos
> « devant » = **aucune encre autour du logo** = rendu net, invisible sur le noir. ✅

## 3) Le cas des DOS (2 styles possibles)

Nos 5 artworks dos ont un **fond plein** (ciel violet/nuit). Deux rendus pro :

- **(A) Poster plein-dos** *(déjà prêt, recommandé)* : on imprime le rectangle complet.
  C'est LE look « affiche synthwave dans le dos », très courant en streetwear premium.
- **(B) Détouré flottant** : je peux détourer le ciel pour que voiture + soleil + texte
  « flottent » sur le noir du vêtement. Plus risqué (peut couper le dégradé du ciel).

👉 Par défaut on part sur **(A)**. Si tu préfères le style flottant sur une pièce, dis-le
moi et je te sors la version détourée en 1 minute.

## 6) Mockups (la vitrine)

Dans le Design Maker → onglet **Mockups** :
- Choisis **2–3 mockups par produit** : un **flat lay** (à plat) + un **modèle porté** fond sombre.
- Pour le dos : ajoute un mockup **vue de dos** (indispensable, c'est l'argument de vente).
- Télécharge les mockups (ils serviront de photos produit sur le site).

## 7) Publier + connecter au site

1. **Créer** les 8 produits sur Printful (garde-les d'abord en **brouillon** le temps de tout régler).
2. Côté site : **Admin → Réglages → Printful** → colle ta **clé API Printful**
   (Printful → *Settings → Developers → API → New token*, type **store**), coche *Activer*.
3. Clique **« Lister mes produits »** → le site récupère les `sync_variant_id`.
4. Pour chaque produit boutique du site, **lie** la variante Printful correspondante + mets
   les mockups comme images produit + le prix du tableau ci-dessus.
5. **Prérequis paiement :** Stripe doit être **actif** (c'est Stripe qui encaisse le client ;
   Printful te débite le coût de prod ; ta marge = différence).

> Règle de fiabilité : jamais d'invention ; rumeur clairement étiquetée.

## 🎯 Les 3 leviers qui font le trafic (par ordre d'impact)

1. **Google Discover + Top Stories** (pic d'actu GTA VI) → peut envoyer des dizaines de milliers de visites sur UN article. C'est LÀ qu'est le gros volume.
2. **Clusters "presque top 3"** déjà en page 1 → à pousser en position 1-3 (gros gain rapide).
3. **Backlinks** (digital PR) → débloque l'autorité pour les head-terms + la citation dans l'Aperçu IA.
